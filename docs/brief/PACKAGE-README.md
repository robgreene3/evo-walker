# EvoWalker Build Package

This package contains:

- `01-RESEARCH-AND-VIABILITY.md` - product/technical analysis and staged scope.
- `02-AGENTS.md` - persistent repository-level instructions; copy to the project root as `AGENTS.md`.
- `03-GPT-5.6-CODEX-MASTER-PROMPT.md` - the one-time Codex request that researches and builds the MVP end to end.

Recommended use:

1. Create an empty repository.
2. Copy `02-AGENTS.md` to the repository root as `AGENTS.md`.
3. Place the other documents under `docs/brief/` if desired.
4. Open the repository in Codex.
5. Paste `03-GPT-5.6-CODEX-MASTER-PROMPT.md` as the initial task.

The package deliberately defines controller evolution as the MVP and defers morphology evolution until reproducibility, performance, persistence, and the critical UI journey pass.
